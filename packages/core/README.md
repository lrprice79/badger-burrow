# @purple-brock/burrow-core

Framework-agnostic engine for Purple Brock Burrow — the provider-less token store (`BadgerBase`), `extendBurrow` / `mergeBurrow`, token resolution, and the style builders (`buildBoxStyles`, `buildTextStyles`) the web and native packages share.

**Needs:** React ≥ 18 (peer). ESM only.

Part of **Purple Brock Burrow** by The Purple Brock — see the
[main README and usage guide](https://github.com/lrprice79/badger-burrow#readme).
